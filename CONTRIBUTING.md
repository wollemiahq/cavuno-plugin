# Contributing

Thank you for helping improve the Cavuno plugin.

Use issues for skill behavior that went wrong, missing workflows, and
documentation gaps. Do not include API keys, OAuth tokens, customer data or
vulnerability reports.

Report vulnerabilities privately as described in `SECURITY.md`.

Pull requests may improve skills, commands and evals. Run
`claude plugin validate .` and the relevant `claude plugin eval` cases
before opening one. Changes to what the connector can do should start as an
issue, since the plugin only uses the public Cavuno API.

By submitting a contribution, you agree that it may be distributed under the
MIT License and that you have the right to submit it.
